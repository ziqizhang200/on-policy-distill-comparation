# 基于在线策略蒸馏的大语言模型后训练方法研究

哈尔滨工业大学本科毕业设计项目。计划在统一模型、任务和训练预算下，比较在线策略蒸馏中不同 KL 方向及全词表、Top-K、K1 监督粒度的效果、稳定性与资源开销。

## 当前状态

已建立统一参考文献库；截至 2026-10-07，`Papers/references.bib` 含 45 条 BibTeX 条目，新增条目的核验状态仍需逐条复查。开题答辩已通过，正式开题报告已形成一版加深研究内容的修改稿，围绕状态分层、Top-K 尾部质量保留和反馈粒度选择展开，尚待导师审阅与实验验证。尚未提供本项目的训练、评估及实验复现命令，也没有本项目实验结果。
