# 基于在线策略蒸馏的大语言模型后训练方法研究

哈尔滨工业大学本科毕业设计项目。计划在统一模型、任务和训练预算下，比较在线策略蒸馏中不同 KL 方向及全词表、Top-K、K1 监督粒度的效果、稳定性与资源开销。

## 当前状态

已建立统一参考文献库；截至 2026-10-07，`Papers/references.bib` 含 40 条 BibTeX 条目，新增条目的核验状态仍需逐条复查。开题答辩已通过，但导师要求加深各研究问题的实际研究内容；目前正在讨论如何在原有在线策略蒸馏、散度和监督粒度框架内形成具体方法。尚未提供本项目的训练、评估及实验复现命令，实验结果待实验验证。
